# Generated tests for inline-example

This directory was generated by the Haskell symbolic execution tool for `inline-example`.

## Files

- `inline-example_original.py`: exact Python-like source text analyzed by the tool.
- `inline-example_stack_program.txt`: compiled stack-language program with instruction addresses.
- `inline-example_test_cases.txt`: human-readable generated test cases.
- `inline-example_test_cases.json`: structured data consumed by `inline-example_run_tests.py`.
- `inline-example_run_tests.py`: Python replay script that executes `inline-example_original.py` for every generated test case.
- `inline-example_README.md`: this file.

## Running the replay

From this directory, run:

```sh
python3 inline-example_run_tests.py
```

The replay script patches `input()` so the Python-like program receives integer input values, matching the analyzed language subset.
Printed lines are compared with the expected output after trimming trailing whitespace from each line.

## Test case format

Each test case records input assignments, expected printed output, the rendered symbolic path condition, and a note identifying the solved symbolic leaf that produced it.
